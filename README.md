2. Clone este repositório:
   ```bash
   git clone https://github.com/gamaroblys/estudos-python.git
   ```
3. Entre na pasta e rode um arquivo:
   ```bash
   cd estudos-python
   python 01-primeiros-passos/ola_mundo.py
   ```
